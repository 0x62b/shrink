# shrink
a project made for the hack club [shrink](https://shrink.hackclub.com/) program. this is a js implementation of [conway's game of life](https://en.wikipedia.org/wiki/Conway%27s_Game_of_Life) encoded into a [data url](https://developer.mozilla.org/en-US/docs/Web/URI/Reference/Schemes/data).

## how to use
open `dist/uri.txt` and paste it into the address bar on your browser. this file contains a data url which encodes the page in `src/index.html` built using `build.mjs`.
